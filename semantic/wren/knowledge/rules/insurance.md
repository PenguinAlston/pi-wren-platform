# 保险业务规则

- 保单状态：01-待核保 02-承保有效 03-暂保单 04-已退保 05-已终止 06-已失效
- 理赔状态：01-待立案 02-待查勘 03-审核中 04-赔付中 05-已结案 06-拒赔 07-撤销报案
- 保全类型：01-信息变更 02-缴费变更 03-受益人变更 04-保额调整 05-保单复效 06-保单挂失 07-退保申请
- 赔付率超过 70% 属于高风险信号，需要关注承保质量
- 重疾险、寿险属于低频高额理赔，医疗险、意外险属于高频低额理赔
- 业务字典统一存储在 sys_dict 表，机构信息在 sys_org 表

# 指标口径

- claim_ratio: 实际赔付金额 / 已赚保费，超过 70% 属于高风险信号（单位：%）
- active_policies: 保单状态为"承保有效"的在保保单数量
- avg_premium: 年交保费合计 / 保单件数（件均保费）
- claim_count: 理赔案件数量
- preserve_count: 保全业务件数
- underwrite_count: 核保记录数量
